# Lattice skill: MCQ authoring

Standing bar for Knowledge seed items and any generated MCQs.

## Parallel-option rule (non-negotiable)

**All alternate answers must match the correct answer in complexity, length, specificity, and register** so the item cannot be solved by “which option looks different.”

Checklist before shipping an item:

1. **Length** — distractors within ~±20% of the correct option’s word count (no one-liner vs paragraph tell).
2. **Specificity** — same density of mechanisms, jargon, and quantitative claims; avoid vague vs precise contrast.
3. **Register** — all options sound like something a strong RS candidate might say in an interview.
4. **Plausible near-misses** — wrong options encode real misconceptions (scaled-wrong, adjacent paper, inverted tradeoff), not jokes or category errors (“Disk RPM”, “illegal to train”).
5. **No stylistic halo** — correct option must not be the only multi-clause, hedge-aware, or citation-flavored choice.
6. **Shuffle check** — after writing, scramble order; if you can still pick by shape alone, rewrite.

## Process

1. Draft the correct answer at the target density.
2. Write three distractors that could pass a quick skim as correct.
3. Run the checklist; tighten until options are visually and rhetorically parallel.
4. Add an explanation that names *why* each near-miss fails (at least in your notes).
